# 聊天输入框模型控件 UI 验收记录

## 已核验

- 模型控件位于输入框底部工具栏右侧，包含运行模式、对话模型、思考强度三个入口。
- 模式菜单展示后端返回的名称、说明和不可用原因。
- 思考强度面板包含模型入口、档位按钮、可用时的滑杆和恢复模型默认强度操作。
- 思考强度面板可以进入模型选择，并提供返回思考面板的按钮。
- 控件使用主题变量，弹层默认向上展开，并限制最大宽度。
- 局部浏览器 DOM 曾成功读取到三个入口：标准模式、跟随默认模型、思考模式。

## 修复项

- 极速锁定时，思考面板标题保持显示“快速”。
- 单档位模型隐藏无效滑杆，避免最小值和最大值相同造成滑块位置计算异常。
- 键盘调整滑杆时延迟到值更新后提交，避免保存上一档位。
- 思考面板进入模型选择和返回时恢复键盘焦点。
- 思考档位在窄屏使用自适应网格并允许文字换行，避免横向溢出。

## 限制

- 当前浏览器页面刷新后连接超时，未完成亮色／暗色和不同视口的截图比对。
- 未读取聊天历史或整页 DOM；相关检查限定在模型控件和输入框局部范围内。
