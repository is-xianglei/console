# 项目概述

## 项目定位

一个基于 Vue 3 + TypeScript 的单页应用（SPA）。

## 技术栈

| 领域 | 技术 | 说明 |
|------|------|------|
| UI 框架 | Vue ^3.5.38 | 强制使用 Composition API 与 `<script setup>` |
| 类型系统 | TypeScript ~6.0.2 | 强制使用，禁止 JavaScript |
| 构建工具 | Vite ^8.1.0 | 使用 `@vitejs/plugin-vue` 与 `@nuxt/ui/vite` |
| 路由管理 | Vue Router ^4.6.4 | - |
| 状态管理 | Pinia 3.0.4 | 统一使用，禁止其他方案 |
| 组件库 | Nuxt UI ^4.10.0 | 交互 UI 优先使用 Nuxt UI 组件 |
| 样式方案 | Tailwind CSS ^4.3.3、CSS Modules、CSS 变量 | 保持样式隔离并支持主题切换 |
| HTTP 请求 | @shentu/request | 基于 axios 封装 |
| 流式通信 | @microsoft/fetch-event-source 2.0.1 | 处理 SSE 流式事件 |
| 组合式函数工具 | @vueuse/core 14.3.0 | 编写或封装组合式函数时，优先考虑是否有可复用的 VueUse 能力 |
| Markdown | markdown-it 14.2.0、highlight.js 11.11.1 | Markdown 解析与代码高亮 |
| 图标 | @iconify-json/lucide、lucide-static | 统一使用 Lucide 图标资源 |
